# 价值投资之王 — 微信小程序云开发版

> 📈 基于微信云开发的智能选股工具，提供早盘集合竞价、尾盘强势股、短线强势股三大选股策略。

## 📋 项目概述

本项目是「价值投资之王」从 PC 端 Flask Web 应用迁移到微信小程序云开发的完整实现。后端基于微信云开发（CloudBase），前端使用微信小程序原生框架，数据源来自东方财富、新浪财经和腾讯行情。

### 核心功能

| 功能 | 页面 | 说明 |
|------|------|------|
| **早盘集合竞价** | `pages/auction/` | 两阶段评分，开盘前捕捉竞价异动股 |
| **尾盘强势股** | `pages/wp2/` | 尾盘综合评分，筛选尾盘拉升潜力股 |
| **短线强势股** | `pages/strong/` | 技术面+基本面双维度评分，捕捉短线爆发股 |
| **大盘环境** | `pages/index/` | 沪深300趋势、波动率、多空判定 |
| **我的** | `pages/mine/` | 版本信息、数据库初始化 |

## 🚀 快速开始

### 1. 环境准备

- [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)（建议 1.05.2111300+）
- 基础库选择 2.20.1+
- 项目 AppID: `your_app_id`

### 2. 打开项目

在微信开发者工具中打开 `D:\wx_jztz` 目录。

### 3. 云环境配置

确保 `miniprogram/config.js` 中的云环境 ID 正确：

```javascript
module.exports = {
  env: 'your_cloud_env_id'
}
```

### 4. 数据库初始化

两种方式：

**方式一：自动初始化（推荐）**
- 运行小程序 → 进入「我的」页面 → 点击「初始化数据库」

**方式二：手动创建**
在云开发控制台 → 数据库 → 新建以下集合：

| 集合 | 说明 | 索引 |
|------|------|------|
| `users` | 用户信息 | `_openid`（自动） |
| `pick_cache` | 选股结果缓存 | `type(升序)+date(升序)` |
| `stock_cache` | 行情数据缓存 | `cachedAt(升序)` |
| `financial_cache` | 财务数据缓存 | `cachedAt(升序)` |

### 5. 部署云函数

在微信开发者工具中：
1. 右键 `cloudfunctions` 目录
2. 选择「创建并部署：所有文件」
3. 等待部署完成（每个约 10-30 秒）

### 6. 云函数配置

| 配置项 | 值 |
|--------|-----|
| 超时时间 | 120 秒 |
| 内存大小 | 512 MB |
| 运行环境 | Node.js 16.13 |

## ⭐ 三大选股策略详解

### 🔥 短线强势股 (`strongPicker`)

**数据源**：东方财富换手率榜(f8) + 涨幅榜(f3) 合并去重

**评分逻辑**（总分100）：

| 维度 | 权重 | 最优区间 |
|------|------|---------|
| 涨幅得分 | 0-25分 | 2-4%（区分创业板） |
| 量比得分 | 0-20分 | 1.5-3倍 |
| 换手率得分 | 0-15分 | 1-8% |
| 振幅得分 | 0-15分 | 3-8% |
| 成交额得分 | 0-10分 | 越大越好 |
| 市值得分 | 0-10分 | 30-100亿 |
| PE得分 | 0-5分 | 0-20 |

**最终评分 = 技术面(60%) + 基本面(40%)**

### 🌅 早盘集合竞价 (`auctionPicker`)

**数据源**：新浪竞价API（3页，涨幅排序）

**两阶段评分**：

- **Phase 1（预筛选 40%）**: 趋势(30) + 量能(30) + 位置(20) + 换手(20)
- **Phase 2（确认 60%）**: 跳空(25) + 量比(25) + 成交额(25) + 大盘(25)

**推荐级别**: ≥80 强烈推荐 | ≥65 推荐 | ≥50 观望 | <50 谨慎

### 🌇 尾盘强势股 (`wp2Picker`)

**数据源**：东方财富涨幅榜(f3) + 量比榜(f10) 合并去重

**评分维度**：涨幅(25) + 换手率(15) + 成交额(15) + 量比(10) + 市值(10) + 振幅(10) + PE(5) + ROE(10)

## 📡 数据源

| 数据源 | 协议 | 用途 |
|--------|------|------|
| 东方财富 | HTTP | 涨幅榜、换手率榜、量比榜、财务数据 |
| 新浪财经 | HTTP | 竞价数据、沪深300行情 |
| 腾讯行情 | HTTP | 个股行情（备用）、K线数据 |

### 多源切换策略

每个选股云函数配备双数据源，主源失败自动切换：

| 云函数 | 主源 | 备用源 |
|--------|------|--------|
| 短线强势股 | 东财换手率+涨幅榜 | 东财涨幅榜+腾讯行情 |
| 尾盘强势股 | 东财涨幅榜+量比榜 | 腾讯行情 |
| 早盘竞价 | 新浪竞价API(3页) | 东财涨幅榜 |

## 🛠 技术要点

### 云函数调用策略

**禁止嵌套调用**（避免超时累加），所有云函数直接 `require` 共享模块：

```javascript
// ✅ 正确：直接 require 共享模块
const { evaluateStock } = require('../scoring/evaluate')

// ❌ 错误：嵌套调用会累加超时
// const res = await cloud.callFunction({ name: 'scoring', data: { action: 'evaluate' }})
```

### 超时保护机制

每一层外部调用都有独立保护：
1. `withTimeout` — 单个API调用超时控制
2. `retryRequest` — 网络失败自动重试2次
3. `fallback` — 失败时返回空数据而非崩溃

### 缓存策略

| 缓存 | 有效期 | 用途 |
|------|--------|------|
| `pick_cache` | 1天 | 选股结果 |
| `stock_cache` | 60秒 | 行情数据 |
| `financial_cache` | 3600秒 | 财务数据 |

## 📊 技术指标

云函数 `techIndicator` 支持以下技术指标计算：

- **MA** - 移动平均线（MA5/MA10/MA20/MA60）
- **MACD** - 指数平滑异同移动平均线（含金叉/死叉检测）
- **RSI** - 相对强弱指标（RSI6/RSI14）
- **KDJ** - 随机指标
- **BOLL** - 布林带（上轨/中轨/下轨/持仓位置）
- **动量** - 5日动量、20日动量

### 五因子评分引擎 (`scoring/evaluate.js`)

| 因子 | 权重 | 包含指标 |
|------|------|---------|
| 价值 | 36% | PE分 + PB分 + ROE分 |
| 质量 | 11% | 毛利率 + 净利率 + 负债率 |
| 成长 | 8% | 营收增长 + 利润增长 |
| 动量 | 12% | 5日涨幅 + 20日动量 |
| 情绪 | 33% | 换手率 + 量比 + 成交额 |

## 👨‍💻 开发注意事项

### 交易时间

- 早盘竞价数据：**9:15-9:30** 最准确
- 尾盘选股：**14:30-15:00** 最佳
- 非交易时间数据源可能返回空数据

### 云开发限制

- 云函数最长执行时间：60秒（需配置）
- 云函数最大内存：512MB
- 免费额度：每月100万次调用 / 10万GBs

### 代码风格

- 使用 `var` 声明变量（云函数环境兼容性）
- 使用 `function` 关键字（非箭头函数）
- 使用 `async/await` 处理异步
- 所有文件使用 UTF-8 无 BOM 编码

## 🔄 部署流程

1. 在微信开发者工具中修改代码
2. 右键 `cloudfunctions` → 部署所有云函数
3. 预览测试功能是否正常
4. 工具 → 上传 → 填写版本号
5. 登录 [微信公众平台](https://mp.weixin.qq.com) → 版本管理 → 提交审核
6. 审核通过后点击「发布」
